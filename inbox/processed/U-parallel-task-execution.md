architecture: implement parallel execution of 2 independent tasks in separate git worktrees — currently tasks run strictly sequentially. When backlog has 2+ tasks with no overlapping deps and no shared file surface (detected by context-compiler's file relevance scan), run both simultaneously in separate worktrees under autopilot/worktrees/{taskId}/. Each gets its own implementation → validation → review pipeline. Results are merged to the integration branch sequentially after both complete (to preserve git history). Concurrency guard: if both touch the same file (detected post-impl via git diff --name-only), the slower one is re-queued. Speedup: 2x throughput on independent tasks, which is ~60% of the backlog. This is the single biggest speed lever available. goal: architecture risk: 4
